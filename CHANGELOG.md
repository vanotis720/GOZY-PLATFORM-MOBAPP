### [v3.3]
- Tech Stack Update: 
Rebuilt the application with Flutter, enabling a single codebase for iOS and Android, improving consistency, scalability, and development efficiency.

- Multi-Theme Support:
Introduced multi-theme support with 4 built-in themes, enabling flexible customization and easy switching of the app’s overall look and feel.

- AI-Powered Enhancements: 
Empower Owners to generate optimized listings with smart pricing insights, while enabling Renters to create structured booking requests effortlessly.

- Service Plan Introduction: 
Introduced a new Service Plan for Owners and Renters, offering reduced service fees, access to AI-powered features, and enhanced overall value across the platform.

- Dynamic Content Support: 
Enabled fully multilingual support, allowing Owners to create and manage content in multiple languages and seamlessly reflect it across the platform.

- Manage Static Content: 
Static content within the application is now fully managed through the Admin Panel, enabling centralized control, easier updates, and real-time reflection of changes across the platform without requiring app releases.

- Coupon Code Feature: 
Enabled renters to apply coupon codes during booking for added savings.

- Push Notification Management:
Introduced an Admin Push Notification section that enables administrators to send notifications directly to Owners, Renters, or all users through the Admin Panel for streamlined communication and announcements.

- UI Enhancements: 
Applied minor design improvements across the app for a cleaner and more intuitive experience.

- Library Upgrades: 
Updated to the latest library versions for improved performance and platform efficiency.

- Bug Fixes & Improvements: 
Addressed some issues and enhanced overall app stability for a smoother experience.
